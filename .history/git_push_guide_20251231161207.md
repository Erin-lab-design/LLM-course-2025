# Git 推送指南 - 同步删除操作到 GitHub

## 问题描述
你在 week5 文件夹中删除了一本书的文件，该文件在 GitHub 上还存在，需要将本地的删除操作同步到远程仓库。

## 解决方案

### 步骤 1: 打开终端并进入项目目录
```bash
cd /Users/mac/LLM-course-2025
```

### 步骤 2: 查看当前状态
```bash
git status
```
这个命令会显示哪些文件被删除了（显示为 `deleted:`）

### 步骤 3: 将所有更改（包括删除）添加到暂存区
```bash
git add -A
```
或者
```bash
git add --all
```

**解释**: 
- `git add -A` 会添加所有更改，包括：
  - 新文件
  - 修改的文件
  - **删除的文件** ✅

### 步骤 4: 提交更改
```bash
git commit -m "Remove deleted book file from week5"
```

### 步骤 5: 推送到 GitHub
```bash
git push origin main
```

如果你的主分支叫 `master`，则使用：
```bash
git push origin master
```

### 步骤 6: 验证
访问你的 GitHub 仓库，检查 week5 文件夹中的文件是否已被删除。

---

## 一键执行脚本

如果你想快速执行，可以直接复制这个命令块：

```bash
cd /Users/mac/LLM-course-2025
git add -A
git commit -m "Remove deleted files from week5"
git push origin main
```

## 常见问题

### Q1: 如果提示需要先 pull 怎么办？
```bash
git pull origin main
# 解决冲突（如果有）
git push origin main
```

### Q2: 如果只想添加删除操作，不想添加其他修改？
```bash
git add -u
```
`-u` 参数只会暂存已跟踪文件的修改和删除，不会添加新文件。

### Q3: 如果想指定删除某个具体文件？
```bash
git rm week5/具体文件名.pdf
git commit -m "Remove specific file"
git push origin main
```
